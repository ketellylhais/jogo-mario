# 🎮 Jogo do Mario

Jogo simples inspirado no Mario Bros, desenvolvido com JavaScript puro.

## 🚀 Tecnologias

- HTML5

- CSS3 (animações)

- JavaScript (manipulação de DOM, eventos)

## ✨ Funcionalidades

- Controle do personagem (pulo)

- Detecção de colisão

- Sistema de pontuação/game over

## 🎯 Aprendizados

- Lógica de jogos

- Manipulação de eventos (keydown)

- Animações com CSS/JS
